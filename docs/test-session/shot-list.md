# テスト回 撮影リスト（iPhone 17 Pro）

## 撮る前の設定
- 設定 → カメラ → フォーマット →「互換性優先」（JPEGで保存される）
- カメラ画面の右上で 48MP をオン
- フラッシュはオフ。照明は全部つける。レンズを拭く
- 基本は**横向き**。Robertの単独写真だけ縦も撮る
- 日本版のiPhoneはシャッター音が消えない → **坐禅中は撮らない**。坐禅の写真は終わったあとに姿勢をとり直してもらって撮る

## 撮影のコツ
- 同じ構図で3〜5枚続けて撮る（目をつぶった写真やぶれた写真を避ける）
- 参加者の荷物、ペットボトル、エアコンのリモコンなどは、画面の外に片付けてから撮る
- 写真の中に文字を入れない（OTAは文字入りの写真を嫌う）
