# 予約の仕組み（GAS）の導入手順

所要時間：15分ほど。Tのアカウント（info@takeshihirata.com）で行う。仕様は `docs/booking-requirements.md`。

## 1. スプレッドシートとスクリプトを作る
1. Google ドライブで新しいスプレッドシートを作る。名前は「Tokyo Zazen Studio 予約」
2. メニューの **拡張機能 → Apps Script** を開く
3. 左の歯車（プロジェクトの設定）→ **タイムゾーン** を「(GMT+09:00) 東京」にする
4. エディタに戻り、`コード.gs` の中身をすべて消して、このフォルダの `Code.gs` を丸ごと貼り付けて保存（Ctrl/⌘+S）

## 2. 初期設定を実行する
エディタ上部の関数の選択欄で、次の3つを順に選んで「実行」を押す。初回は権限の確認が出るので許可する（「このアプリは確認されていません」→ 詳細 → 移動）。

1. `setupSheets`：シート3枚（reservations / calendar / settlement）ができる
2. `fillCalendar`：3ヶ月先までの火・木の行が入る。**木曜は受付オフ**（法人の確認待ち）。祝日は自動でオフ（Google の祝日カレンダーが読めない場合は memo に「祝日未確認」と出るので、手でオフにする）
3. `installTriggers`：自動メールと集計のタイマーが入る

## 3. 個人の設定を入れる（Script Properties）
歯車（プロジェクトの設定）→ 一番下の **スクリプト プロパティ** → 「プロパティを追加」。

| プロパティ | 値 | 必須 |
|---|---|---|
| `PAYMENT_LINK` | Stripe の Payment Link の URL（¥9,000、「数量の変更を許可」をオン、1〜6） | 確定メールに必要 |
| `VENUE_DIRECTIONS` | 住所と駅からの道順（改行してよい） | 前日リマインドに必要 |
| `ROBERT_EMAIL` | Robert のメールアドレス | 前日の人数連絡に必要 |
| `ADMIN_EMAIL` | 新しい予約の通知先。空ならこのアカウント | 任意 |
| `REPLY_TO` | お客さんの返信先。空ならこのアカウント | 任意 |
| `REVIEW_URL` | お礼メールに載せるレビューのURL | 任意 |

未設定のまま該当の自動メールの時間になると、メールは送られず、Google から「スクリプトのエラー」の通知が届く（設定を入れれば次の回で送られる）。

## 4. Web アプリとして公開する
1. 右上の **デプロイ → 新しいデプロイ** → 種類の選択（歯車）で **ウェブアプリ**
2. 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
3. 「デプロイ」→ 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーして、Claude に渡す
   → Claude が `site/index.html` の `ENDPOINT` に入れて公開する

**コードを直したとき**は、デプロイ → デプロイを管理 → 鉛筆 → バージョン「新しいバージョン」→ デプロイ。これをしないと反映されない（URL は変わらない）。

## 5. 動作確認
1. 公開中のサイトのフォームから、自分宛てにテストで1件送る
2. 「【予約】…」の通知と、英語の受付メールが届くことを確認
3. reservations の status を「確定」にする → 1時間以内に支払いリンクつきのメールが届くことを確認
4. 確認が終わったらテストの行を消す

## ふだんの使い方
- **新しい予約が来たら**：OTA の予約状況を見て、status を「確定」か「不可」に変える（メールは自動）
- **支払いの通知が Stripe から来たら**：status を「支払済」にして、各 OTA の在庫を減らす。notes_staff に「OTA在庫 済」
- **OTA で予約が入ったら**：reservations に1行足す。id は `OTA-` で始める、status は「確定」、session_date・session_time・party_size・source（gyg など）を入れる。Robert への人数連絡と月末集計に入る
- **体験の後**：status を「参加済」か「No-show」に。24時間以内のキャンセルは「直前キャンセル」（Robert への支払い対象）
- **休みの日**：calendar の accepting のチェックを外す（最大10分で反映）
- **3ヶ月ごと**：`fillCalendar` をもう一度実行して先の日程を足す
- **毎月1日**：settlement に先月の枠ごとの人数と、Robert への支払額が出る
